# adr_longshort

A random-forest cross-sectional long-short on US-listed Chinese companies (ADRs and direct listings), after Gu, Kelly and Xiu, "Empirical Asset Pricing via Machine Learning" (2020): sixteen price-and-volume characteristics, annual refits, equal-weight quintiles, with the short leg restricted to names trading at least $3m a day, the cut below which retail borrow eats the spread. Everything needed to rebuild the model, reproduce the backtest and generate this month's positions is in the repository, data included.

- `docs/MODEL.md`: the model, its inputs, the refit protocol, what it has learned, and the rule that turns forecasts into positions.
- `docs/STATS.md`: forecast quality, quintile portfolios, borrow sensitivity, the $500,000 account backtest, Monte Carlo, the last five years, cross-checks.
- `docs/CHINA_ADR_RF.pdf`: both as one document, with the figures.

## Setup

```
git clone git@github.com:eschwarzzz/adr_longshort.git && cd adr_longshort
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # numpy, pandas, scikit-learn 1.7.2, joblib, scipy, matplotlib, yfinance, pytest
python3 -m pytest -q                     # unit tests on synthetic data, plus one check against the shipped forecasts (about 2 minutes)
```

Scripts import the `adr_longshort` package from the repository root, so run them from there (or `pip install -e .`).

## What runs

| Script | What it does | Time |
|---|---|---|
| `python3 run_live.py [YYYY-MM] [equity]` | this month's long and short lists and dollar positions from the shipped data and `model/rf_next.joblib` | 1 min |
| `python3 verify.py` | rebuilds features for the last two months, scores them, refits the 2026 forest and recomputes the quintile Sharpe; all must match the shipped files | 2 min |
| `python3 build_panel.py` | daily prices → monthly research panel with targets (`results/panel.csv`) | 1 min |
| `python3 refit.py [--check]` | annual refits 2010–2026 → `results/predictions_rf.csv`, `model/*.joblib`, hyperparameters, importances; `--check` stops if the forecasts differ from the shipped ones | 1 min |
| `python3 backtest.py [--quick]` | quintile statistics, borrow variants, the $500k account with Monte Carlo and nulls, the last five years → `results/` | 10 min (`--quick`: seconds) |
| `python3 make_charts.py` | figures 2–6 and the five-year PDF pages from the backtest outputs | 1 min |
| `python3 trend_correlation.py [sg_trend.csv]` | correlation of the strategy's monthly returns with trend-following: your own SG Trend Index series, or free fund proxies from Yahoo | 1 min |
| `python3 fetch_data.py [--test]` | refresh prices, T-bill and ETF benchmarks from Yahoo and FRED (the Kaggle archive for delisted names is shipped, not refreshed) | 10 min |
| `python3 docs/make_stats.py` | regenerate `docs/STATS.md` from the backtest outputs | seconds |
| `python3 docs/make_pdf.py` | rebuild `docs/CHINA_ADR_RF.pdf` (needs pandoc and tectonic) | 1 min |

The full chain from raw prices is `fetch_data.py → build_panel.py → refit.py → backtest.py → make_charts.py → docs/make_stats.py → docs/make_pdf.py`. With the shipped data, `refit.py --check` reproduces `results/predictions_rf.csv` to machine precision, and `backtest.py` reproduces the tables in `docs/STATS.md` (seeds are fixed).

## Layout

```
adr_longshort/      the package: clean_prices (daily cleaning), features (16 characteristics, ranks, targets), rf_model (fit / refit / load / predict),
                    portfolio (quintile rule with the $3m floor, volatility-targeted sizing), data (loaders)
data/               yf_prices.csv.gz (Yahoo, currently listed names, with the SOE extensions), kaggle_patch/stocks/*.csv (delisted names to April 2020),
                    fred_DTB4WK.csv, benchmarks_monthly.csv, universe.csv; provenance in data/README.md
model/              rf_2026.joblib (behind the 2026 backtest months), rf_next.joblib (for the next refit cycle), rf_hyperparams_by_year.csv,
                    feature_importance.csv, feature_spec.json
results/            predictions_rf.csv (every scored ticker-month, with the research ensemble's forecast for comparison), quintile and borrow tables,
                    the account backtest tables and Monte Carlo JSON, figures, research_quintile_returns.csv (the thirteen research strategies, for the deflated Sharpe)
docs/               MODEL.md, STATS.md (generated by make_stats.py), CHINA_ADR_RF.pdf, make_pdf.py
tests/              pytest
```

## Using the model on new data

`run_live.py` is the reference: load prices (`load_prices`), build the panel (`build_panel`), rank within the month over the tradeable names (`rank_transform`), score with a saved bundle (`load`, `predict`), and form the book (`holdings`, `dollars_a_side`, `weights`). Ranks must be computed over a universe like the one the model was fitted on, US-listed Chinese companies with price ≥ $1 and ≥ $100k a day; the model treats a missing characteristic as the cross-sectional median.

Refit each December with `refit.py` after `fetch_data.py` and `build_panel.py`; the protocol trains on 2001..Y−3 and validates on Y−2..Y−1.

## Limits

Names that delisted after April 2020, other than twelve SOEs carried through their Hong Kong lines, are missing for their final months (survivorship). Borrow schedules in the backtest are assumptions keyed to daily volume, not quotes. Short legs were five names until 2017. Details and the cross-checks are in `docs/STATS.md`.
